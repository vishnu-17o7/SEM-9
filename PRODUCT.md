# Product

## Register

product

## Users

You, the developer — building and running CTI (cyber threat intelligence) and CV (computer vision) lab projects as SEM 9 coursework. The hub is your personal launchpad: browse 30 projects across two labs, view details, run scripts, and see terminal output in one place.

## Product Purpose

A unified dashboard that organizes 18 CTI projects and 12 CV experiments under a single navigation model. Each project or experiment has a detail page with description, metadata, run controls, and output display. The hub replaces the need to open separate terminals or navigate project directories by hand.

Success looks like: you open one URL, find any project in seconds, run it with one click, and see the result immediately.

## Brand Personality

**Analytical · Craft · Sharp**

The tone is technical but considered — like a well-maintained lab notebook. Precise enough for CTI threat analysis, visual enough for CV experiments. The code itself is the portfolio; the hub demonstrates the same quality it organizes.

Voice: specific, factual, unadorned. Verbs over adjectives. "Classify emails as phishing or legitimate" beats "Leverage advanced NLP for email security."

## Anti-references

- Generic SaaS dashboards with sidebar nav + card grids (the current hub before redesign)
- "AI-generated" looks: gradient heroes, purple/teal accents, Inter everywhere, card-in-card, frosted glass
- Over-designed developer tools that prioritize "cool" over readability
- Dark mode as default "because it's a tool" — let the content decide

## Design Principles

1. **Tool-like clarity.** Every page answers "what can I run here and what will it do?" with minimal friction. The interface gets out of the way.
2. **Craft as evidence.** Clean CSS, considered typography (Fraunces display + IBM Plex Sans body + JetBrains Mono code), proper OKLCH tokens. The hub itself demonstrates the quality expected from the labs it hosts.
3. **Restraint as respect.** Information first, decoration second. Typography does the hierarchy work. No gradient text, no glassmorphism, no invented metrics.
4. **Consistency across labs.** CTI and CV projects follow the same interaction patterns. The hub unifies two domains under one mental model — catalogue grid → detail page → run script → see output.
5. **Technical, not cold.** The interface has personality through typographic choices and spacing rhythm, not through decorative elements. It feels made, not generated.

## Accessibility & Inclusion

No formal WCAG level specified. Default to best practices: ≥4.5:1 body text contrast, keyboard-navigable controls, semantic HTML, responsive down to 320px.
